# QuizApp

**QuizApp** is a web-based interactive quiz application built using **HTML, CSS, and JavaScript**. It allows users to answer multiple-choice questions and receive real-time feedback, providing a simple and engaging way to practice knowledge or test learning. The project demonstrates frontend development skills including DOM manipulation, event handling, and responsive UI design.

---

## Overview

- Frontend-only quiz application; no backend required  
- Multiple-choice questions with immediate score display  
- Clean and user-friendly interface  
- Easily customizable to add or modify questions  

This project is ideal for demonstrating proficiency in **vanilla JavaScript**, building interactive web interfaces, and structuring frontend projects professionally.

---

## Features

- Interactive question interface with multiple-choice options  
- Real-time scoring and final result display  
- Responsive design suitable for desktop and mobile  
- Easily extendable with new questions or categories

## Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Edge, Safari)  
- Optional: Text editor for customization (VS Code, Sublime, etc.)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Manasi-16-08/QuizApp.git
cd QuizApp
```
2. Open index.html in your browser:

-Double-click the file, or

-Right-click → Open With → Browser

---
### Usage

1. Start the quiz by selecting answers for each question

2. Click Next to proceed to the next question

3.After the last question, your total score will be displayed

---
### Customizing Questions

Open script.js and modify the quizData array:

```javascript
const quizData = [
  {
    question: "What is 2 + 2?",
    a: "3",
    b: "4",
    c: "5",
    d: "6",
    correct: "b"
  },
  // Add more questions here
];
```
